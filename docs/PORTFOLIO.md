# Bangladesh GeoForecast — Live Weather & Flood-Risk Explorer

Developed by Kazi Md. Jabed Hossain, this interactive Web GIS integrates model weather forecasts with location-based exploration across Bangladesh. A seven-day timeline, hourly precipitation charts, transparent 24/48/72-hour aggregation, and an experimental rainfall-pressure indicator support careful interpretation of environmental information.

The application demonstrates React and TypeScript development, Leaflet web cartography, asynchronous API integration, forecast time handling, GeoJSON validation, Turf-based polygon measurement, and reproducible static deployment through GitHub Actions. Scientific limitations and data provenance are documented throughout: the rainfall indicator is an unvalidated research demonstration, not a flood prediction or official warning service.
